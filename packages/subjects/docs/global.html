UriPatch

Vytvoří "stringovatelný" objekt reprezentující kanonickou aplikací definovanou URI cestu ve tvaru: - bez `:id`: `/{app}/{model}/{action}` - s `:id`: `/{app}/{model}/{action}/{:id}` Objekt je určený pro postupné skládání a odvozování cest napříč aplikací: - sdílení společného základu (např. `app` nebo `app+model`) - tvorbu odvozenin přes `.change(...)` bez mutace původního objektu - pohodlné použití v routeru, linkách a šablonách díky "stringovatelnosti" ### Stringovatelnost Vrácený objekt se chová jako string: - `String(obj)` vrátí finální cestu - template literal: `` `${obj}` `` vrátí finální cestu - `obj.path` obsahuje totéž explicitně ### Odvozování bez mutace (immutable styl) Metoda `.change(patch)` vrací NOVÝ URI objekt s aplikovanými změnami. Původní objekt zůstává nedotčen, takže je bezpečné ho sdílet napříč moduly. ### Zkratky Kromě `.change(...)` poskytuje i zkratky: - `.app("...")` - `.model("...")` - `.action("...")` - `.id(true|false)` (alias pro `withId`) - `.idParam(":id")` (změna názvu parametru id)
Type:
  • object
Properties:
Name Type Attributes Description
path string Finální cesta (např. `"/app/group/view"` nebo `"/app/group/view/:id"`).
segments Object Normalizované segmenty, ze kterých byla cesta složena. Pozn.: pokud `segments` budeš ručně měnit, `path` se tím nezmění (je spočítaný). Doporučení: segmenty používej jen pro čtení.
toString function Vrací `path`. Umožňuje použití v template literal a při `String(obj)`.
valueOf function Vrací `path`. Doplňková string/primitive konverze.
Symbol.toPrimitive function <optional>
 Vrací `path` pro implicitní konverzi (např. `` `${obj}` ``).
change function Vytvoří nový `UriBuilder` s aplikovaným patchem (libovolná část URI může být změněna).
app function Zkratka pro `change({ app })`.
model function Zkratka pro `change({ model })`.
action function Zkratka pro `change({ action })`.
id function Zkratka pro `change({ withId: on })`. Default `true`.
idParam function Zkratka pro `change({ idParam: p })`. Default `":id"`.

Examples
// Základ pro konkrétní model:
const GroupView = uri({ app: "app", model: "group", action: "view" });

String(GroupView)        // "/app/group/view"
String(GroupView.id())   // "/app/group/view/:id"
// Odvozené akce nad stejným modelem:
const Group = uri({ app: "app", model: "group", action: "view" });
const GroupEdit = Group.action("edit").id(true);
const GroupDelete = Group.action("delete").id(true);

String(GroupEdit)   // "/app/group/edit/:id"
String(GroupDelete) // "/app/group/delete/:id"
// Přepnutí id parametru:
const UserView = uri({ app: "app", model: "user", action: "view" }).id(true).idParam(":userId");
String(UserView) // "/app/user/view/:userId"
